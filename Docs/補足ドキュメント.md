# デザインパターン簡易まとめ

## Factory / Registry（登録型の生成）
- 採用箇所:
  - `Assets/Scripts/*/*.cpp`（多くのファイル）
  - `REGISTER_SCRIPT_FACTORY(ClassName);`
- 目的:
  - スクリプトを登録しておき、**エンジン側が名前から動的生成できるようにする**ため。

## State（状態遷移）
- 採用箇所:
  - `Assets/Scripts/Player/Player.cpp`
  - `Assets/Scripts/Player/Player.h`
  - `Update()` 内で `UpdateNormal()` / `UpdateDodgeState()` / `UpdateDownState()` を分岐
- 目的:
  - **プレイヤーの状態（通常・回避・ダウン）ごとの処理を分離**し、
    監視や遷移を安全・明快にするため。

## Strategy（攻撃パターンの切り替え）
- 採用箇所:
  - `Assets/Scripts/Enemy/Enemy.h`（`enum class AttackPattern`）
  - `Assets/Scripts/Enemy/Enemy.cpp`（`UpdateAttack()` / `FireBurst()` / `FireMissile()` / `UpdateRam()`）
- 目的:
  - **敵の攻撃方法をパターンで切り替え**、
    挙動追加や調整をしやすくするため。

## Factory / Spawner（生成責務の集約）
- 採用箇所:
  - `Assets/Scripts/Generator/Generator.cpp`
  - `Assets/Scripts/Enemy/EnemySpawner.cpp`
- 目的:
  - 弾・ミサイル・地形・敵などの**生成や管理を一箇所に集約**し、
    生成ロジックの散在を防ぐため。

## Shared State（共有状態 / 擬似グローバル）
- 採用箇所:
  - `Assets/Scripts/UI/uiState.h`
  - `Assets/Scripts/UI/uiState.cpp`
  - `Assets/Scripts/UI/PoseBackend.cpp`, `PoseClose.cpp`, `PoseReturnTitle.cpp`
- 目的:
  - ポーズUI関連スクリプト間で、
    **状態（開閉・選択項目）を共有**するため。
